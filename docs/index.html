SRC/MAIN.RS
use vdb::{Metric, VectorDb};

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let temporary = tempfile::tempdir()?;
    let db = VectorDb::open(temporary.path())?;
    let docs = db.create_collection("docs", 3, Metric::Cosine)?;
    let ids = docs.upsert_batch(&[
        (vec![1.0, 0.0, 0.0], serde_json::json!({"tags": ["rust"]})),
        (vec![0.0, 1.0, 0.0], serde_json::json!({"tags": ["docs"]})),
    ])?;
    let hits = docs.query(&[1.0, 0.0, 0.0], 10)
        .ef_search(128).execute()?;
    assert_eq!(hits[0].id, ids[0]);
    Ok(())
}

07 / ALPHA BOUNDARIES
Know the
current contract.
The alpha prioritizes coherent state and recoverable writes. These constraints shape how you should use it today.
Insert means insert.
upsert_vector always creates a new ID. Updating existing vectors is not implemented.
Serialized operations.
Atomic batches share one logical transaction and vector-file sync. Operations remain serialized. Incremental graph refresh still copies graph vectors and rewrites the full snapshot.
Local filesystems.
Linux/macOS on supported local filesystems. Network filesystems and external file mutations are unsupported.
Reserved capabilities.
Async, quantization, and IVF flags have no implementation yet. LMDB resizing is not automatic.
